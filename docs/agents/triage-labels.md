# Triage Labels

Скиллы говорят о пяти канонических ролях. Этот файл сопоставляет роли с реальными строками меток в трекере.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение                                 |
| ------------------------ | --------------------- | ---------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить issue          |
| `needs-info`             | `needs-info`          | Ждём от автора дополнительную информацию |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описано, готово для AFK-агента |
| `ready-for-human`        | `ready-for-human`     | Нужна реализация человеком               |
| `wontfix`                | `wontfix`             | Не будем делать                          |

Когда скилл упоминает роль (например, «применить AFK-ready метку»), используй соответствующую строку из таблицы.

Меняй колонку «Метка в нашем трекере», если поменяется словарь меток.
