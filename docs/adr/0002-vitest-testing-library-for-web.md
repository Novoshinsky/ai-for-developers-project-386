# Тесты веба на Vitest и Testing Library с моком сгенерированного SDK

Тесты компонентов запускаются в Vitest с окружением `jsdom`, а сетевой слой
мокается через `vi.mock("@/lib/api")`, без MSW. Компонентные тесты проверяют
интерфейс, а не транспорт: сгенерированный SDK — тонкая обёртка над `fetch`,
которую мы не хотим тестировать заново. MSW был бы ближе к продакшену, но
добавляет service worker и настройку ради одного эндпоинта. Если позже
понадобятся интеграционные тесты через настоящий HTTP, решение стоит пересмотреть.
