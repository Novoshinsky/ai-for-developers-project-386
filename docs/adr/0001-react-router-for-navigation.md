# Навигация в SPA через react-router

Главная страница ведёт на страницу записи, и у каждой страницы должен быть свой
адрес: по ссылке `/booking` можно перейти, обновить её или отправить коллеге.
Мы выбрали `react-router` в декларативном режиме (`BrowserRouter` + `Routes`)
вместо условного рендера и самописного роутера на `history API`: библиотека даёт
готовые маршруты, ссылки и `MemoryRouter` для тестов без браузера. Условный
рендер не даёт адресу страницы записи существовать самостоятельно, а самописный
роутер пришлось бы расширять при первом же усложнении маршрутов.
