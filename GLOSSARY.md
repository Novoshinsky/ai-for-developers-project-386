# Календарь звонков

Сервис бронирования звонков: гость выбирает тип встречи и свободное время, а
встреча попадает в календарь. Учебный проект Хекслета по мотивам Cal.com.

## Язык

**Календарь звонков**:
Сервис бронирования звонков, который живёт в этом репозитории.
_Avoid_: календарь, планировщик, приложение, сервис встреч

**Главная страница**:
Экран по адресу `/`, который рассказывает про сервис и ведёт на страницу
записи.
_Avoid_: лендинг, домашняя страница, home page, стартовая

**Страница записи**:
Экран по адресу `/booking`, где гость создаёт бронирование. «Запись» здесь —
действие гостя, а не сущность.
_Avoid_: страница бронирования, форма записи, booking page, страница выбора

**Тип встречи**:
Вариант звонка, на который гость может записаться, например знакомство или
консультация.
_Avoid_: тип события, event type, услуга, каталог типов встреч, встреча

**Слот**:
Промежуток времени, свободный для записи на выбранный тип встречи.
_Avoid_: окно, время, таймслот, свободное время

**Бронирование**:
Подтверждённая запись гостя на слот.
_Avoid_: резервация, букинг, запись (как сущность), встреча

**Гость**:
Человек, который записывается на звонок через сервис.
_Avoid_: пользователь, клиент, посетитель, юзер
